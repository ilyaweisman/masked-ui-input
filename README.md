# masked-ui-input
A masked UI input component for a fixed length regex.

## TypeScript template setup

This repository now includes a minimal TypeScript project structure.

### Scripts

- `npm run build` — compile TypeScript to `dist`
- `npm run start` — run the compiled output
- `npm run dev` — run the project directly with `ts-node`

### Getting started

1. Install dependencies:

```bash
npm install
```

2. Build the project:

```bash
npm run build
```

3. Run the compiled app:

```bash
npm run start
```

4. Or run in development mode:

```bash
npm run dev
```
